# yaml-test-suite fixtures

Copied from https://github.com/yaml/yaml-test-suite at the release tag `data-2022-01-17` (commit 6e6c296ae9c9d2d5c4134b4b64d01b29ac19ff6f), the generated data of the suite. The licence is in LICENSE (MIT; copied from the repository's `main` branch at commit da267a5c4782e7361e82889e76c0dc7df0e1e870).

Each directory holds one case: `in.yaml`, `in.json` (when the case is not an error), `test.event`, `error` (when the case is an error) and `===` (the name). Cases with numbered variants (for example `2G84/00`) are kept in the same layout. There are 402 cases, 94 of them error cases. Files are byte-exact copies. The `out.yaml` files and the alias directories are not copied.
